# Homebrew tap for Grab-it

[Grab-it](https://kerwincarpede.github.io/grab-it/) is a free, open source screenshot tool: capture, mark up, and paste anywhere.

```sh
brew install --cask kerwincarpede/tap/grab-it
```

Grab-it keeps itself up to date, so `brew upgrade` leaves it alone. Remove it with `brew uninstall --cask grab-it`, or `brew uninstall --zap --cask grab-it` to remove its settings too.

`Casks/grab-it.rb` is updated automatically by each [Grab-it release](https://github.com/kerwincarpede/grab-it/releases). Report problems in the [Grab-it repository](https://github.com/kerwincarpede/grab-it/issues).
